# Pauth40 2.2.0 - port Uno Platform

O Pauth40 deixa de estar limitado ao Windows. A mesma aplicação passou a ser
construída com **Uno Platform** e .NET 10, mantendo o desenho, o cofre local e
os formatos de dados da versão WPF.

## Plataformas

- **Windows** (WinAppSDK) - `Pauth40-2.2.0-win-x64.exe`
- **Linux x64** (Skia/X11) - `Pauth40-2.2.0-x86_64.AppImage` e `Pauth40-2.2.0-linux-x64.tar.gz`
- **macOS** (Apple Silicon e Intel) - `Pauth40-2.2.0-osx-arm64.zip` e `Pauth40-2.2.0-osx-x64.zip`
- **WebAssembly** - `Pauth40-2.2.0-wasm.zip`
- **Android, iOS e tvOS** - compilados a partir do projeto `linux/Pauth40` com os workloads .NET e a assinatura de cada plataforma

## Novidades

- Interface única para todas as plataformas: ecrã de segurança, autenticador,
  definições, atualização obrigatória e captura de ecrã na mesma janela.
- Cofre local compatível com a versão WPF: `accounts.dat` continua a ser
  cifrado com AES-256-GCM e os backups `.pauth40` são interoperáveis.
- No Windows a recuperação local continua a usar DPAPI. Nas restantes
  plataformas a chave do cofre é protegida por uma chave AES-GCM do dispositivo.
- Captura de ecrã por plataforma: GDI no Windows, ferramentas nativas em Linux e
  macOS, `screencapture` no macOS e seletor de imagens em Android, iOS, tvOS e
  WebAssembly.
- Leitura de QR com SkiaSharp e ZXing.Net, sem dependência de `System.Drawing`.
- Atualização automática no Windows (`.exe`) e Linux (`.AppImage`); em macOS,
  Android, iOS, tvOS e WebAssembly a atualização é manual.

## Instalação

### Windows

Execute `Pauth40-2.2.0-win-x64.exe`. É um executável autónomo; não precisa de
instalar o .NET.

### Linux

Opção A - AppImage:

```bash
chmod +x Pauth40-2.2.0-x86_64.AppImage
./Pauth40-2.2.0-x86_64.AppImage
```

Opção B - pacote portátil:

```bash
tar -xzf Pauth40-2.2.0-linux-x64.tar.gz -C Pauth40
./Pauth40/install-linux.sh
```

### macOS

Extraia o zip adequado ao processador (arm64 para Apple Silicon, x64 para
Intel) e arraste `Pauth40.app` para a pasta Aplicações. Na primeira execução,
use **Abrir** no menu de contexto para autorizar a aplicação não assinada.

### WebAssembly

Sirva o conteúdo do zip com qualquer servidor HTTP estático:

```bash
unzip Pauth40-2.2.0-wasm.zip -d pauth40-wasm
python3 -m http.server 8080 --directory pauth40-wasm
```

## Notas

- O cofre é local. A única chamada de rede automática é a verificação de
  versões no GitHub; a recuperação por e-mail usa o servidor SMTP configurado
  pelo utilizador.
- Os ficheiros de idioma `pt-PT.json` e `en-US.json` continuam a poder ser
  editados ou substituídos sem recompilar a aplicação.
- O projeto WPF original permanece no repositório para referência; a versão Uno
  está em `linux/`.

[en-US]
# Pauth40 2.2.0 - Uno Platform port

Pauth40 is no longer Windows-only. The application is now built with **Uno
Platform** and .NET 10 while keeping the design, the local vault and the data
formats of the WPF build.

## Platforms

- **Windows** (WinAppSDK) - `Pauth40-2.2.0-win-x64.exe`
- **Linux x64** (Skia/X11) - `Pauth40-2.2.0-x86_64.AppImage` and `Pauth40-2.2.0-linux-x64.tar.gz`
- **macOS** (Apple Silicon and Intel) - `Pauth40-2.2.0-osx-arm64.zip` and `Pauth40-2.2.0-osx-x64.zip`
- **WebAssembly** - `Pauth40-2.2.0-wasm.zip`
- **Android, iOS and tvOS** - built from `linux/Pauth40` with the .NET workloads and each platform's signing

## What's new

- A single interface on every platform: security gate, authenticator, settings,
  mandatory update and screen capture share one window.
- The local vault is compatible with the WPF build: `accounts.dat` remains
  AES-256-GCM encrypted and `.pauth40` backups are interchangeable.
- On Windows local recovery still uses DPAPI. On the other platforms the vault
  key is protected by a device-bound AES-GCM key.
- Per-platform screen capture: GDI on Windows, native tools on Linux and macOS,
  `screencapture` on macOS, and the image picker on Android, iOS, tvOS and
  WebAssembly.
- QR decoding with SkiaSharp and ZXing.Net, with no `System.Drawing` dependency.
- Automatic updates on Windows (`.exe`) and Linux (`.AppImage`); macOS, Android,
  iOS, tvOS and WebAssembly update manually.

## Installation

### Windows

Run `Pauth40-2.2.0-win-x64.exe`. It is a self-contained executable; no .NET
installation is required.

### Linux

Option A - AppImage:

```bash
chmod +x Pauth40-2.2.0-x86_64.AppImage
./Pauth40-2.2.0-x86_64.AppImage
```

Option B - portable package:

```bash
tar -xzf Pauth40-2.2.0-linux-x64.tar.gz -C Pauth40
./Pauth40/install-linux.sh
```

### macOS

Extract the zip that matches the processor (arm64 for Apple Silicon, x64 for
Intel) and drag `Pauth40.app` to Applications. On first launch use **Open** from
the context menu to allow the unsigned application.

### WebAssembly

Serve the zip contents with any static HTTP server:

```bash
unzip Pauth40-2.2.0-wasm.zip -d pauth40-wasm
python3 -m http.server 8080 --directory pauth40-wasm
```

## Notes

- The vault is local. The only automatic network request is the GitHub version
  check; e-mail recovery uses the SMTP server configured by the user.
- The `pt-PT.json` and `en-US.json` language files can still be edited or
  replaced without rebuilding the application.
- The original WPF project stays in the repository for reference; the Uno build
  lives in `linux/`.
